# 百度网盘智能转存 · Edge 专版

一个本地 Microsoft Edge Manifest V3 侧边栏扩展。它直接使用当前 Edge 中的百度网盘登录状态，不要求复制 Cookie；分享目录触发账号单次数量上限时，才自动展开并分批转存。

## 安装（约 1 分钟）

1. 在 Edge 地址栏打开 `edge://extensions`，开启左侧的“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本文件夹（里面能直接看到 `manifest.json`）。
3. 打开并登录 `https://pan.baidu.com/disk/main`，再点击工具栏中的百度网盘图标。

## 使用

粘贴分享链接 → 确认提取码与保存目录 → 点击“开始转存”。复制自分享页的 `#list/path=...` 片段会被自动清除。

转存期间请保持 Edge 侧边栏打开。若百度触发验证码、账号安全验证或访问频率限制，请先在百度网盘网页完成验证，稍后再试，不要连续重复提交。

## 隐私与范围

- Cookie 不会显示、复制或发送给第三方，请求仅发往 `pan.baidu.com`。
- 目前只支持个人版 `/s/1…` 分享，不处理企业版 `apaas` 链接。
- 同名文件默认跳过；同名目录会尝试合并内部内容。
- 百度网盘图标来自百度网盘官网，其商标与图标权利归百度所有。本扩展仅供个人学习和自用。
